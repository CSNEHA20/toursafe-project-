# TourSafe Threat Register

| ID | Threat Title | Vulnerability Description | Inherent Severity | Implemented Mitigation | Residual Risk | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **THR-01** | **NoSQL Injection in Request Payloads** | Malicious JSON keys containing `$gt`, `$ne`, `$where` injecting query operators into MongoDB | `HIGH` | Recursive deep inspection & rejection via `sanitize_nosql_input` on all incoming API request bodies. | Low | **CLOSED** |
| **THR-02** | **Refresh Token Compromise & Replay** | Stolen refresh tokens replayed by malicious actors to maintain persistent access | `HIGH` | Refresh Token Rotation (RTR) with automatic token family reuse detection and immediate family-wide revocation. | Low | **CLOSED** |
| **THR-03** | **SSRF on External Webhook Destinations** | Adversaries configuring webhook endpoints pointing to internal metadata or private cloud VPC IPs | `CRITICAL` | `validate_outbound_url` enforcing strict scheme allowlists (HTTP/HTTPS) and blocking private/loopback/cloud metadata IP ranges. | Low | **CLOSED** |
| **THR-04** | **Audit Log Tampering & Repudiation** | Malicious administrators editing MongoDB documents to remove incriminating audit trails | `CRITICAL` | Cryptographic SHA-256 hash chaining (`previous_hash` linking) with automated integrity verification (`verify_audit_chain`). | Very Low | **CLOSED** |
| **THR-05** | **Kinematic GPS Teleportation / Spoofing** | Attackers transmitting synthetic GPS updates to disrupt emergency search and rescue operations | `HIGH` | Haversine velocity validation (>350 m/s threshold) + Mock Location flag rejection in `validate_gps_sample`. | Low | **CLOSED** |
| **THR-06** | **Telemetry Replay & Out-of-Order Injection** | Replaying previously recorded IMU accelerometer / gyroscope data to spoof falls/crashes | `MEDIUM` | Sequence number monotonicity checking + timestamp freshness validation in `validate_telemetry_sequence_and_replay`. | Low | **CLOSED** |
| **THR-07** | **Emergency SOS Flood / Exhaustion** | Flooding emergency endpoints causing denial of service to genuine tourists in peril | `HIGH` | Safety-critical deduplication (`check_sos_rate_and_deduplicate`): preserves dispatch while correlating rapid duplicates. | Low | **CLOSED** |
| **THR-08** | **AI Copilot Indirect Prompt Injection** | Untrusted incident notes or documents tricking LLM into triggering unauthorized responder dispatch | `CRITICAL` | Pre-LLM prompt sanitization + Tool execution authorization sandbox + Two-Phase Verification Action Tokens with human confirmation. | Low | **CLOSED** |
| **THR-09** | **Cross-Site Scripting (XSS)** | Injection of `<script>` tags or `javascript:` URLs into tourist incident descriptions or admin notes | `MEDIUM` | HTML entity escaping via `sanitize_xss_string` and strict Content-Security-Policy headers. | Low | **CLOSED** |
| **THR-10** | **Credential Stuffing & Brute Force** | Automated dictionary attacks against authentication endpoints | `HIGH` | Sliding-window `RateLimiter` on `/login` and `/register` with progressive delays and security event monitoring. | Low | **CLOSED** |
