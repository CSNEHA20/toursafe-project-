# TOURSAFE — PROMPT 31
COMPLIANCE, GOVERNANCE, PRIVACY & REGULATORY READINESS

## Core Directives
1. Build **COMPLIANCE READINESS**, not false certifications. Do not claim TourSafe is certified with GDPR, DPDP, ISO 27001, or SOC 2 without qualified legal assessment.
2. Implement **Privacy as a System Property** with genuine data minimization, consent versioning/withdrawal, retention policies, safe deletion workflows, and purpose limitation.
3. Protect safety-critical operational records — deletion must respect **Legal Holds** and ongoing emergency investigations.
4. Establish comprehensive Data Inventory, RoPA, Vendor Processor Register, Access Reviews, Time-Bounded Break-Glass PAM, and Auditor Mode.
