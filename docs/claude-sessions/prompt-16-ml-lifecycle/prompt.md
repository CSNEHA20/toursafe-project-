CORE OBJECTIVE:
Build a production-oriented ML lifecycle around the existing LSTM anomaly detection system.

RAW TELEMETRY -> DATA VALIDATION -> DATASET CONSTRUCTION -> FEATURE ENGINEERING -> DATASET VERSION -> TRAINING -> EXPERIMENT -> EVALUATION -> MODEL VALIDATION -> MODEL REGISTRY -> APPROVAL -> STAGING -> SHADOW / CANARY -> PRODUCTION -> MONITORING -> DRIFT DETECTION -> RETRAINING DECISION

The system must NEVER automatically replace the production model merely because a new model was trained.
