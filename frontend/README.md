# TourSafe RN

Frontend-only React Native / Expo prototype for the TourSafe travel safety app.

## Run locally

1. Install dependencies: `npm install`
2. Start web: `npm run web`
3. Or start native Expo: `npm start`

## Demo access

- Authority: `admin@toursafe.com` / `admin@123`
- Authority alt: `admin@tnpol.gov.in` / `admin@123`
- Client: enter any email and use the mock OTP flow

## Notes

- Backend and database are mocked for now.
- `EXPO_PUBLIC_DEV_BYPASS=true` keeps the demo flows available during development.
